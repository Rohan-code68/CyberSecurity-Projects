# CyberSecurity Projects

A collection of hands-on cybersecurity projects focused on offensive security, security analysis, and SOC incident investigation.

## Projects

### 01. SQL Penetration Testing
- Performed SQL injection testing in a controlled lab environment.
- Identified and analyzed vulnerable SQL queries.
- Used Burp Suite and manual testing techniques.
- Documented findings and recommended remediation measures.

### 02. Privilege Escalation
- Investigated privilege escalation vulnerabilities in a controlled Linux environment.
- Performed system enumeration and analyzed permissions and misconfigurations.
- Identified potential escalation paths.
- Documented findings and mitigation techniques.

### 03. Data Exfiltration
- Investigated simulated data exfiltration activity.
- Analyzed network traffic and suspicious communication patterns.
- Identified indicators of compromise and potential attack behavior.
- Documented detection and mitigation recommendations.

### 04. SOC Incident Report
- Investigated a simulated cybersecurity incident from a SOC analyst perspective.
- Analyzed logs, network activity, and indicators of compromise.
- Created an incident timeline and assessed the impact.
- Documented containment, remediation, and prevention recommendations.

## Objective

To develop practical skills in penetration testing, security monitoring, incident investigation, and cybersecurity analysis through hands-on laboratory projects.

> All activities were performed in controlled and authorized lab environments for educational purposes.
